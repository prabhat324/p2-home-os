# P² Home OS

P² Home OS is a self-hosted home infrastructure platform.

## Nodes

core-01
- Raspberry Pi 5
- Storage
- Home Assistant
- Homepage
- AdGuard
- Monitoring

compute-01
- HP ZBook Fury
- Ubuntu Server
- Docker
- AI
- Jellyfin
- GPU Compute

## Principles

- Infrastructure as Code
- Documentation First
- Version Controlled
- Reproducible
- Secure
- Observable
- Recoverable
